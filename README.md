# Digital Soft Net — Repair Website

A responsive business website for Digital Soft Net, a phone, computer, laptop, and gaming console repair business in Zouk Mosbeh, Mount Lebanon.

## Live Demo

https://digitalsoftnet.netlify.app

## Features

- Service listings for phones, computers, laptops, and gaming consoles
- Searchable repair services
- Repair request form that prepares a message for WhatsApp
- Direct phone and WhatsApp contact links
- Responsive layout and scroll animations

## Built With

- HTML
- CSS
- JavaScript

## Project Goal

Built as a practical web development project to learn front-end development and create a useful online presence for a local repair business.
